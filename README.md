# 知ってる知らない？漢字・四字熟語・慣用句

iOS アプリ「知ってる知らない？漢字・四字熟語・慣用句」の、不具合のご報告とご要望の受付先です。

- **不具合のご報告・ご要望:** [Issues](https://github.com/saimas/kanji-site/issues) の「New issue」からお寄せください（無料の GitHub アカウントが必要です）。お使いの iPhone の iOS バージョンと、起きたことの手順を書いていただけると助かります。
- **サポート（よくある質問）:** <https://saimas.jp/apps/kanji/support/>
- **プライバシーポリシー:** <https://saimas.jp/apps/kanji/privacy/>
- **App Store:** <https://apps.apple.com/jp/app/id6821605696>

---

This repository is the issue tracker for the iOS app 知ってる知らない？漢字・四字熟語・慣用句. To report a bug or request a feature, open an [issue](https://github.com/saimas/kanji-site/issues); a free GitHub account is required. Please include your iOS version and the steps that led to the problem. The support page and the privacy policy are on saimas.jp, in Japanese and English: [support](https://saimas.jp/apps/kanji/support/?lang=en), [privacy policy](https://saimas.jp/apps/kanji/privacy/?lang=en).
